# QuickRep 1.3.1

JSON and export collections preserve NULL, numbers and booleans returned by MapRow. UTF-8 conversion applies only to strings. XLSX export preserves empty cells and scalar types, and no longer requires an application logo file.

No dependency, schema, cache-key or access-control changes. API signatures are unchanged. Consumers that relied on coercing MapRow's numeric or boolean values to strings must use their actual types.
